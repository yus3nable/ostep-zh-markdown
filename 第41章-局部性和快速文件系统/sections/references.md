# 参考资料

[MJLF84]“A Fast File System for UNIX”Marshall K. McKusick, William N. Joy, Sam J. Leffler, Robert S. Fabry ACM Transactions on Computing Systems.August, 1984. Volume 2, Number 3.pages 181-197.McKusick 因其对文件系统的贡献而荣获IEEE 的Reynold B. Johnson 奖，其中大部分是基于他的FFS 工作。在他的获奖演讲中，他讲到了最初的FFS 软件：只有1200 行代码！现代版本稍微复杂一些，例如，BSD FFS后继版本现在大约有5 万行代码。

[P98]“Hardware Technology Trends and Database Opportunities”David A. Patterson Keynote Lecture at the ACM SIGMOD Conference (SIGMOD ’98) June, 1998磁盘技术趋势及其随时间变化的简单概述。

[K94]“The Design of the SEER Predictive Caching System”G. H. Kuenning MOBICOMM ’94, Santa Cruz, California, December 1994据Kuenning 说，这是SEER 项目的较全面的概述，这导致人们收集这些跟踪记录（和其他一些事）。

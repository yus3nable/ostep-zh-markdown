# 操作系统导论

一台计算机如何同时运行许多程序？多个线程怎样共享数据？断电之后，文件为什么还能保存下来？《操作系统导论》（OSTEP）围绕虚拟化、并发与持久性，解释操作系统如何管理资源、协调程序并保存数据。

**[从第 1 章开始阅读](第01章-关于本书的对话/sections/introduction.md) · [查看全书目录](目录.md)**

## 这本书讲什么

- **[虚拟化](书前与导语/第一部分-虚拟化/README.md)**：从进程、CPU 调度到地址空间与分页，理解操作系统如何让多个程序共享处理器和内存。
- **[并发](书前与导语/第2部分-并发/README.md)**：从线程、锁到条件变量和信号量，理解共享数据时会出现什么问题，以及如何协调多个执行流程。
- **[持久性](书前与导语/第3部分-持久性/README.md)**：从 I/O 设备、磁盘到文件系统和日志，理解数据如何存储、组织与恢复。后续章节继续讨论分布式系统与网络文件系统。

书中穿插了教授与学生的对话，用问题引出主题，再通过机制、代码和例子展开。各章的参考资料与作业适合在读完正文后继续学习；附录还提供虚拟机监视器和实验项目等内容。

## 怎样阅读

第一次阅读，可以从前两章了解全书的问题与结构，再按虚拟化、并发、持久性的顺序学习。熟悉某些主题后，也可以通过全书目录或搜索直接找到相关章节。

阅读代码示例时，先想一想它会产生什么结果，再运行并比较。遇到调度、地址转换或并发问题，尝试手动推演一次执行过程；做完章节作业后，回到正文检查自己的理解。

## 使用阅读网站

- **打开章节**：点击左侧章名直接阅读正文。对话章点击后即可读完；有多个小节的章节，点击章名旁的箭头展开小节目录。
- **连续往下读**：使用页底的“上一页”和“下一页”，按正文顺序切换。多小节章节也可以点击标题下方的“整章阅读”，在同一页阅读整章。
- **查找内容**：使用顶部搜索框输入术语或问题，例如“页表”“信号量”“文件系统”。
- **调整显示**：点击顶部的明暗切换按钮选择阅读主题。手机上点击左上角菜单打开目录。
